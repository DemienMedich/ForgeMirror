# Обязательная поставка приложения

- Программа всегда должна иметь актуальную пользовательскую версию в формате SemVer `MAJOR.MINOR.PATCH`. Используй один канонический источник версии и передавай его в приложение, метаданные EXE, установщик и имя релизного артефакта. Не оставляй противоречащие друг другу или условные версии вроде `0.5`, `dev` и `latest`.
- Перед завершением релизной задачи собери настоящий установщик Windows (`Setup.exe` или `MSI`). Одна portable-папка или ZIP не считаются установщиком, если пользователь явно не попросил именно portable-вариант.
- Установщик должен поддерживать установку и обновление поверх предыдущей версии с постоянным идентификатором приложения, создавать корректную запись удаления и сохранять пользовательские данные. Не включай в него локальные базы, профили, фотографии, секреты, облачные настройки и другие данные разработчика.
- По возможности используй установку для текущего пользователя без прав администратора. Удаление программы не должно удалять пользовательские данные без отдельного явного выбора пользователя.
- Перед сдачей проверь в изолированном каталоге или профиле: запуск установщика, запуск установленного EXE без среды разработки в `PATH`, соответствие отображаемой версии версии установщика, обновление поверх предыдущей версии и штатное удаление. Не называй релиз готовым только потому, что проект скомпилировался.
- Зафиксируй в документации точный путь к установщику, его версию и результат проверки. Если проект публикуется через PharosHub, версия и исполняемый файл в manifest Хаба должны совпадать с проверенным релизом.
