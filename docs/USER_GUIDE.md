# JobSkill — пользовательская документация

## Обзор
JobSkill — инструмент ведения прогресса художника/дизайнера с двумя интерфейсами:
- **CLI** (`JobSkill.exe`) — управление профилями, задачами и XP через консоль.
- **GUI** (`JobSkillGui.exe`) — визуальный контроль профиля, добавление опыта, редактирование правил и каталога навыков.

Данные хранятся локально в `data/` (`data/meta/gameplay.ini`, `data/skills.txt`, `data/*.ini` для профилей). В GUI и CLI используется одна и та же логика расчёта опыта.

## Сборка и запуск (Windows)
```powershell
# CLI
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release

# GUI
cmake -S . -B build-gui `
  -DBUILD_IMGUI_GUI=ON `
  -DIMGUI_DIR="Z:/CPP/JobSkill/libs/imgui" `
  -DCMAKE_TOOLCHAIN_FILE="C:/tools/vcpkg/scripts/buildsystems/vcpkg.cmake" `
  -DVCPKG_TARGET_TRIPLET=x64-windows `
  -DVCPKG_PWSH_PATH="C:/Program Files/PowerShell/7/pwsh.exe"
cmake --build build-gui --config Release --target JobSkillGui
```
Готовые бинарники: `build/Release/JobSkill.exe`, `build-gui/Release/JobSkillGui.exe`.

## Хранение данных
- **Профили:** `data/0001.ini`, `data/0002.ini`, … (плюс `data/archive/*.ini` для архивных).
- **Геймплейные правила:** `data/meta/gameplay.ini`.
- **Каталог навыков:** `data/skills.txt` (список `Название|Вес|Описание`).
- **Разметка окон GUI:** `data/meta/gui-layout.ini` (можно удалить для сброса).

## Каталог навыков
- Просмотр: окно **Skill Catalog** в GUI.
- **Добавить навык:** кнопка «Добавить навык» → ввести имя, вес (0.5–1.6) и описание. Сохраняется в `skills.txt`, сразу доступен в распределении XP.
- **Удалить навык:** выбрать в списке → «Удалить навык». Навык удаляется из каталога и из всех профилей.
- Вес навыка влияет на вклад в общий уровень при начислении XP по этому навыку.

## Профили
- **Создать/архивировать/восстановить/удалить:** кнопки в GUI («Главное меню») или команды CLI (`archive <id>`, `restore <id>`, `delete <id>`).
- **Активный профиль** отображается в панели **Профиль**: уровень, суммарный XP, категории, навыки, радиальная диаграмма и последние действия.
- **Последние действия** показывают ключевые события (выдача XP, улучшение категорий, штрафы), форматируются в ASCII для читаемости.

## Правила начисления опыта
Настройки задаются в окне **Gameplay Rules** (GUI) или файлом `data/meta/gameplay.ini`. Параметры сразу применяются в CLI и GUI.

### Уровень профиля
- Требуемый XP для уровня N: `base + linear*(N-1) + quadratic*(N-1)^2`.
- Общий уровень растёт при каждом добавлении глобального XP.

### Категория задачи
- Каждая задача относится к категории E/D/C/B/A. Базовый XP берётся из `Category base XP` для выбранной категории.
- Оценка (1–10) умножает базу на нелинейный множитель: `(score/10)^1.35` (нижняя граница 0.1).

### Фокус по навыкам
- Пользователь распределяет 100% по навыкам. Берётся максимальная доля `maxShare` (в долях от 0 до 1).
- Фокус-бонус: `focus_base_bonus + focus_additional_bonus * maxShare` (задаётся в правилах).
- Предварительный пул навыкового XP: `baseXP * scoreMultiplier * focusBonus`, затем делится по долям между выбранными навыками.

### Повтор задачи
- Если текущая оценка не выше лучшей в этой категории, к глобальному XP применится штраф `repeat_reward_factor` (по умолчанию 0.35 = 35%). Навыковый XP не режется.

### Штраф за простои
- Если последняя задача была больше 30 дней назад, запускается «прогрев»: `recoveryWarmupTasks` задач идут со штрафом `recovery_reward_factor` к глобальному XP (навыковый XP без штрафа). Счётчик уменьшается при каждой задаче.

### Деградация категорий
- **Отключена** (kDecayEnabled=false): кулдауны категорий и понижение оценок не применяются.

## Добавление опыта (GUI, окно Add Experience)
1. Выбрать категорию (E–A) и оценку (1–10).
2. Распределить доли навыков (сумма 100%). Ползунки автоматически подгоняют баланс.
3. Просмотреть подсказки: базовый XP категории, множитель за оценку, фокус-бонус и прогноз пула XP.
4. Нажать **Apply**: навыковый XP записывается в навыки; глобальный XP учитывает штрафы повторов/прогрева; при улучшении категории обновляются лучшие оценки.

## CLI команды (основное)
- `list` — список профилей.
- `skills` — список навыков с весами.
- `login <id|name>` — открыть профиль.
- `task` — добавление задачи с диалогом распределения XP.
- `addxp <skill> <amount>` — выдать XP конкретному навыку.
- `archive <id>` / `restore <id>` / `delete <id>` — управление профилями.
- `quit` — выход.

## Известные настройки/ограничения
- Локаль: вывод и парсинг чисел принудительно через classic locale, чтобы исключить артефакты (��� вместо пробелов).
- Деградация категорий выключена; чтобы вернуть, нужно вручную включить kDecayEnabled в `main.cpp` и `gui/GuiApp.cpp`.
- Каталог навыков — единый источник истины: удаление навыка вычищает его из всех профилей.
