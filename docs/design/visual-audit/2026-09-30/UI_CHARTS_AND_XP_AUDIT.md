## Конечный объём проверок

- Renderer: **224 состояния** = 7 масштабов × 2 ширины × (6 Report + 4 Log + 6 Profile fixture). Масштабы 90 / 100 / 110 / 125 / 150 / 175 / 200%, ширины 640 / 320. Есть нули, sparse/dense, длинный период, большие числа, отсутствующие временные метки и недоступный progress XP.
- Каждая непустая текстовая область проверяется независимым glyph measurement, bounds и pairwise overlap. Числа/даты дополнительно не должны дробиться. Проверяются координаты и значения точек, полные доступные данные и actual widget height, не только объявленный sizeHint.
- Ширина возвращается после сужения, шрифт меняется на том же экземпляре и возвращается. Это отдельная проверка от семи новых экземпляров.
- Report: **72 реальных selector-контекста** = 8 группировок × (всё время + 4 периода × сравнение off/on). Проверяются значения текущего периода и независимый 12-месячный audit-trend. Это не приёмка всех восьми таблиц или их экспорта.
- XP: две формы на семи масштабах; три участника / три навыка с длинными русскими именами, invalid allocation, quick OnlyActive, сортировка по ID, фильтр без изменения распределения, footer/default/Tab/Return. Отмена сравнивает точные байты профилей, tasks, audit и last-good; при 100/200% numpad Enter сохраняет XP в fresh workspace.
- Native-снимки 100/200% сохраняются отдельно. Full renderer capture не доказывает доступность прокрутки: viewport и scroll-bottom снимаются дополнительно.

## Промежуточные результаты и причины исправлений

Первый native-прогон графиков прошёл 224 состояния и 72 selector-контекста, но итоговая небольшая перестройка top-skill name/XP требует повтора. Первый native-прогон XP обнаружил реальные слишком узкие / низкие cell widgets: при 90% participant был **51×32** вместо minimum hint **65×32**, skill — **39×29** вместо **53×32**. При 100% снимок показывал обрезку `100` и оценки навыка. Дефект исправляется измерением именно реальных дочерних SpinBox после наследования font/style, размерами числовых столбцов и строк и повторным измерением после reorder. Эти первые failing logs не удаляются и не выдаются за финальный PASS.

Первая экспериментальная смена шрифта в regression-driver случайно достигала 250% при исходных 200%, за пределом поддерживаемого контракта; теперь смена/возврат на том же экземпляре ограничены 90–200%. Продукт для этого не менялся. Все исходные проверки читаемости поддерживаемых семи масштабов сохранены.

## Поставка и оставшиеся гейты

Настоящий Setup 0.6.93 собран; Windows-only PATH normal/help/version и qwindows проверены, equivalent isolated install .92 → update .93 → uninstall прошёл. Package startup probes не доказывают native focus/exposure; это отдельно доказывает console-driver для форм/renderer.

Ранее открытые native hover, повтор 18×7 страниц, остальные page states, service/cloud forms, transition/bulk-task формы и timed motion/system-policy остаются в [конечной матрице](../../UI_ACCEPTANCE_MATRIX.md). Следующий service-form проход ограничен [семью существующими семействами](../../UI_SERVICE_FORMS_INVENTORY.md). User installation 0.6.87, production workspace, ImGui-baseline и PharosHub не меняются.
