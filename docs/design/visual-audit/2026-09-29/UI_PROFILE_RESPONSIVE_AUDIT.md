# Адаптивный обзор профиля — 29.09.2026

## Что изменено

На минимальном окне 800×520 тест обнаружил, что overview шире доступной области на 170–255 px. Последовательная проверка размеров выявила три причины: 3-колоночная сетка обзорных действий, четыре колонки встроенной таблицы с неадаптивной шириной и длинная сводка задач без переноса. Теперь KPI равномерно занимают доступную ширину и переносятся, если ряд не помещается; действия переходят на следующие строки; сводка и таблица задач не расширяют страницу. Полные значения ячеек по-прежнему доступны по подсказкам.

Палитра, данные, порядок и тексты действий не менялись. Новых анимаций нет: по плану дополнительные motion-переходы начинаются после стабилизации статичных экранов.
