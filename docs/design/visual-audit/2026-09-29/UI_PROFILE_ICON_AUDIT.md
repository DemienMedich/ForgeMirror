## Решение

Раньше достижение без файла изображения показывало знак вопроса, который выглядел как сломанная иконка. Теперь рисуется небольшой контурный медальон с геометрической звездой. Используются только текущие цвета текста и акцента; подсказка и accessibility name по-прежнему содержат название, навык и бонус. Для просроченного достижения Qt применяет штатный disabled-вариант значка.

Это локальная коррекция P1, а не перестройка страницы. Заполненный обзор профиля пока состоит из длинной последовательности равновесных блоков; перестановка запланирована после проверки других режимов профиля и минимальной ширины.
