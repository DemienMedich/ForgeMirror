## Что не следует делать дальше автоматически

Не повторять уже принятые системный motion, hover, Tab, историю, каталожные длинные строки и облачные подтверждения ради нового счётчика. Не добавлять новые украшения только потому, что пользователь ещё не ответил. Не расширять задачу дизайна до новых форматов3D или всех комбинаций cloud domain-операций.

## Незакрытое решение

Показанные пользователю profile/tasks находятся в visual-audit/2026-10-16/design-review. На просьбу оценить выразительность пользователь ответил «Покажи, пропустил»; снимки повторно показаны. Это не согласие и не отказ. Нужно получить содержательную оценку визуального направления: достаточно ли выразительности при сохранённой плотности. До неё общий результат не объявляется согласованным.

Документ не превращает все исторические ограниченные PASS в исчерпывающую проверку каждой комбинации. Перед окончательным закрытием необходима сверка строк исходной UI_ACCEPTANCE_MATRIX с UI_ACCEPTANCE_CURRENT, с сохранением записанных исключений и без новых вымышленных требований.
