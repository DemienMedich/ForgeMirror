## Очередь до завершения

1. Один изолированный интерактивный проход: шапка (hover/focus/disabled), Tasks Tab после .103, два вида motion с разворотом и отключением. Снять конкретные ограничения инструментов, если оценка presented frames недоступна; не повторять неудачный synthetic hover без нового основания.
2. Сверка недостающих состояний семи семейств форм с имеющимися доказательствами; затем только отсутствующие просмотры/исправления. Не расширять задачу на несвязанные backend-сценарии.
3. Обновить итоговую матрицу по фактическим результатам, проверить финальную поставку при изменении продукта и завершить аудит исходной цели. Пользовательское одобрение вкуса полезно, но само отсутствие ответа не является техническим блокером.

Ни один из этих пунктов не разрешает менять production-данные, ослаблять проверки или удалять ImGui-baseline. CONTINUITY сохраняется отдельно. Новый релиз ради этой документации не создаётся.
