Предусмотренный исходной матрицей масштаб90–200% сохраняется; геометрический PASS не расширять до визуального PASS всех состояний. Пока пакеты не сопоставлены с конкретными результатами, завершение всего плана не доказано. Это очередь проверки, не разрешение на production операции и не расширение функционального объёма.
