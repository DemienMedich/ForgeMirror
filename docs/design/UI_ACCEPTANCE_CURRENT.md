## Следующие действия без повторения пройденного

1. Изолированное живое окно .105 с заполненными синтетическими задачами: клавиатурный выход из таблицы и видимый focus.
2. Адресный просмотр ещё не принятых вариантов пресетов/восстановления по существующим фикстурам. Не расширять UI-задачу на новые backend-функции.
3. Системное отключение motion: отдельно подтвердить фактическое переключение Windows и восстановление прежнего состояния; не объявлять кодовый вызов SPI end-to-end проверкой.
4. После закрытия остатка — доставка принятого кандидата и проверка локального Hub на соответствие реально установленному EXE.

## Ограничение инструмента подтверждено повторно

Прочитаны актуальные guidance/api/confirmations computer-use 26.1007.21434. Поддерживаются click, keyboard, scroll, drag и снимки, но нет hover/move-pointer и видеозахвата. Не повторять прежний synthetic hover без нового основания и не выдавать click за чистый hover. Системные настройки в этом проходе не менялись.

Исходный критерий «вся матрица» остаётся в силе. Устаревшие записи «плавность не оценена пользователем», «.105 Setup не создан» и старый запрет native traversal не должны заново порождать уже выполненную работу.
