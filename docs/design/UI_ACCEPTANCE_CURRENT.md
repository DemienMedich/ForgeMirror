### Живая проверка заполненной таблицы — 11.10.2026

Кандидат .105 запущен отдельно с новым синтетическим workspace `build-qt/keyboard-0.6.105-de5d38a8f2d14145974eefb2be82e76a/workspace`, созданным штатным PrepareUiVisualAuditWorkspace. PID93396, возвращённое окно5112566. Пять задач видны; выбор первой строки даёт явную рамку ячейки. Первый Tab убирает рамку ячейки, следующий Tab показывает фокус на ссылке «все 4» под таблицей. Таким образом, выход из заполненной таблицы в этом живом сценарии подтверждён; все остальные комбинации клавиш этим не принимаются. Accessibility focused_element упорно сообщал о search и противоречил изображению — не использован как доказательство. Alt+F4 закрыл тестовое окно. Рабочая установка и системная настройка motion не менялись.

1. Изолированное живое окно .105 с заполненными синтетическими задачами: клавиатурный выход из таблицы и видимый focus.
2. Адресный просмотр ещё не принятых вариантов пресетов/восстановления по существующим фикстурам. Не расширять UI-задачу на новые backend-функции.
3. Системное отключение motion: отдельно подтвердить фактическое переключение Windows и восстановление прежнего состояния; не объявлять кодовый вызов SPI end-to-end проверкой.
4. После закрытия остатка — доставка принятого кандидата и проверка локального Hub на соответствие реально установленному EXE.
