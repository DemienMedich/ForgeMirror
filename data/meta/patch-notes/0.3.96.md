# ForgeMirror 0.3.96

- Подготовлена база для будущей смены GUI без жёсткой привязки к текущему слою ImGui.
- Доменные типы задач/проектов/профессий/ярлыков/пайплайна вынесены из `gui/GuiTypes.inc` в `include/AppDomainTypes.h`.
- Добавлен общий `AppContext` (`include/AppContext.h`) для верхнего GUI-слоя.
- Инициализация и cloud reload сведены к общим helper-функциям в `gui/GuiAppContext.inc`.
- После cloud pull/quick sync теперь единообразно перезагружаются профили, задачи, проекты, профессии, правила, баннер и хранилище.
