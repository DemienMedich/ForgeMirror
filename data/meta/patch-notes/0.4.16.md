# ForgeMirror 0.4.16

- Tasks: откат удаления задачи с XP больше не пытается вычитать только `total_xp`; теперь у участника задачи хранится rollback-snapshot XP-зависимого состояния профиля и удаление восстанавливает навыки, category progress, penalty/recovery state и task counters.
- Tasks: формат `participants` расширен обратно совместимо, поэтому новые задачи пишут snapshot для корректного rollback, а старые задачи без snapshot продолжают откатываться по legacy-сценарию.
- Stability: rollback не затирает сторонние поля профиля вроде кошелька, профессии или ачивок, потому что snapshot покрывает только состояние, которое меняется от выдачи XP по задаче.
