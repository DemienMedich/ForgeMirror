# ForgeMirror Qt 0.6.35

- Reject profile saves when the active profile file changed since it was selected or read.
- Replace profile files atomically from unique sibling temporary files; never delete the prior file as a fallback.
- Require reload before retrying a rejected stale save.

Verification: Core smoke replaces a selected profile externally, checks that the stale save fails, and verifies the replacement bytes remain unchanged. Installer lifecycle evidence is recorded in `docs/releases/ForgeMirror-0.6.35.md`.
