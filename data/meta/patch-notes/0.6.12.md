# ForgeMirror 0.6.12

Qt migration checkpoint release. Keeps the existing storage formats and stable ImGui branch unchanged.

- Administrator audit now classifies privacy-safe project and catalog mutation outcomes, including rollback failures for transactional deletions.
- Statistics adds deadline-state grouping and task mutations now appear under core audit events.
- No project/catalog names, IDs, descriptions, credentials or raw service errors are added to the new core event messages.
- Qt administrator login persists only in the isolated Qt workspace. The login dialog shows that workspace path for troubleshooting; no password values should be shared.
