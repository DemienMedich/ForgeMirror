# ForgeMirror 0.5.52

- Зафиксирован roadmap полезности для официального принятия ForgeMirror в команде.
- Добавлен `AppTeamValueReportService` для управленческих метрик по задачам, проектам, дедлайнам, pending XP и исполнителям.
- CSV-экспорт админской статистики теперь дополняется блоком `TeamValueReport`.
- Smoke-тест проверяет расчёт отчёта: просрочку, задачи без проекта/этапа, pending XP и вклад исполнителя.
