# ForgeMirror 0.4.21

- Cloud UX: меню `Облако` теперь показывает drift по `meta/tasks.json` и `meta/pipeline.json` как отдельные file-card блоки, а не только как общий счётчик расхождений.
- Cloud UX: из drift-блока можно сразу открыть `Задачи` или `Пайплайн`, чтобы перейти к проблемному модулю без ручной навигации.
- Cloud sync: для `tasks.json` и `pipeline.json` добавлен safe-resolve workflow `Принять облачную` / `Оставить локальную` с резервными копиями в `meta/updates` перед заменой версии.
