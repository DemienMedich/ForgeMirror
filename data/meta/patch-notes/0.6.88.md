# ForgeMirror Qt 0.6.88

- Adds an optional, short transition for the active sidebar marker; the preference is saved per workspace.
- Honors Windows client-area animation settings and immediately updates the marker when motion is disabled.
- Replaces the blanket UI animation ban with a bounded motion policy. The palette, layout density, and migrated workflows remain unchanged.
- Preserves the ImGui baseline at version 0.5.54.
