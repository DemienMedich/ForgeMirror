# ForgeMirror 0.5.49

- Автовосстановление распространено на связанные данные проектов.
- Повреждённые JSON сохраняются в `meta/updates` перед восстановлением.
- После recovery приложение показывает предупреждение и записывает событие в журнал.
- Повторная загрузка восстановленных данных больше не создаёт повторное предупреждение.
