# ForgeMirror 0.4.19

- Projects: добавлен явный project-level status-slice по handoff и XP: summary показывает активные проекты, проекты с pending XP и просрочку без необходимости читать каждую строку таблицы.
- Projects: в фильтрах появился persistent-переключатель `Только ждут XP`, а в сортировке режим `По XP handoff`, чтобы быстро выводить проекты, где выдача опыта ещё не завершена.
- Tasks/Projects UX: блок `Проекты в задачах` теперь тоже показывает сводку по активному потоку, pending XP и просрочке, а в строках проектов появилось отдельное состояние `Handoff ждёт`.
