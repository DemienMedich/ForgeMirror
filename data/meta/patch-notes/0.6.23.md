# ForgeMirror Qt 0.6.23

- Ported the stable Ctrl+F10 interface reset shortcut to the Qt client.
- Reset display, Pomodoro and 3D viewer preferences atomically, then restart into the same Qt workspace.
- Preserve selected profile identity, personal trust state, administrator credentials and session preference, cloud settings, presets and user files.
- Added regression coverage for reset defaults and preservation of unrelated workspace data.
