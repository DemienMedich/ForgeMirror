# ForgeMirror 0.4.22

- Cloud UX: в меню `Облако` появился restore-flow по последним backup-копиям `meta/tasks.json` и `meta/pipeline.json`, сохранённым в `meta/updates`.
- Cloud sync: можно отдельно восстановить локальный или облачный backup-снимок обратно в локальный workspace, не трогая облако автоматически.
- Safety: перед восстановлением текущая локальная версия тоже сохраняется в `meta/updates`, чтобы откат из backup не был одноразовым и безвозвратным.
