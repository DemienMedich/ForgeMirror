# ForgeMirror 0.6.18 Qt patch notes

- Migrated the stable ImGui overall-alpha setting as a persistent 60–100% opacity control for the Qt main window.
- Imported the legacy `[style] alpha` value and included opacity in custom and legacy Qt layout presets.
- Added tests for UI adjustment, settings persistence, preset round-trip, legacy import and main-window restoration.
- Modal dialogs remain opaque; the fixed palette is unchanged.
