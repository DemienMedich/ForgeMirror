# ForgeMirror Qt 0.6.36

- Validate cloud-pull recovery against both the original and expected applied file hashes before rolling back any target.
- Stop recovery without partial rollback when a local file has a third, externally changed state.
- Keep older pull journals safe: automatically finish only if all targets still match their recorded pre-images.
- Make `--version` and `--help` exit before the GUI workspace and main window are created.

Verification: Qt smoke covers normal recovery, a mixed multi-file external conflict, retry after the conflict is resolved, conservative handling of legacy journals, and process-boundary checks for `--version` and `--help`. Installer lifecycle evidence is recorded in `docs/releases/ForgeMirror-0.6.36.md`.
