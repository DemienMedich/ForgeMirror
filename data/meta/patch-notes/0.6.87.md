# ForgeMirror Qt 0.6.87

- Completes the mapped Qt migration of the 18 legacy workspace tabs, including the remaining Pomodoro, 3D viewer, portfolio, profile, skill catalog, pipeline, and task-creation workflows from stages 242–267.
- Restores task priority and status selection during creation, including the existing XP handoff for tasks created as completed.
- The Qt/core regression suites cover the migrated workflows, administrator session persistence across process restarts, and isolated workspace behavior.
- This is the Qt client release. The preserved ImGui baseline remains version 0.5.54.
