# ForgeMirror 0.5.08

- UX plan 8: добраны empty-state для профиля, профессий и админ-статистики.
- Админ-статистика: таблицы простоя и прогрева больше не показывают строки из дефисов при пустом результате.
- Профессии: пустые списки профилей/навыков и состояние без выбранной профессии используют общий empty-state.
- Профиль: отсутствие профилей и состояние без выбранного профиля показывают общий empty-state с контекстным действием.
- QA: smoke проверяет empty-state контракты профиля, профессий и админ-статистики.
