# ForgeMirror 0.4.23

- Cloud UX: restore-блок в меню `Облако` теперь показывает не один последний backup, а несколько последних снимков для `meta/tasks.json` и `meta/pipeline.json`.
- Cloud UX: у каждого snapshot видны время создания, тип источника (`локальный`, `облачный`, `перед восстановлением`) и отдельная кнопка восстановления.
- Safety: если backup-файлов накопилось больше, чем помещается в quick-list, UI явно показывает, что остальные снимки остаются в `meta/updates`.
