# ForgeMirror Qt 0.6.45

- Reject task mutations when the on-disk task file no longer matches the snapshot loaded by this window.
- Preserve externally changed task data on stale single, bulk, delete, status, XP-finalize and project-detach operations; ask the user to reload before retrying.
- Cache unchanged task file revisions within the process to avoid reparsing task JSON on every save.
- Cover conflict preservation, project-delete rollback, and successful retry after reload in core smoke tests.

This optimistic guard does not eliminate a write that races after comparison and before replacement. Full coordinated cross-process and multi-file transaction support remains open.
